# Brand assets

Copied from the private marketing repo `theTemple10/philos_eduos-marketing`,
folder `brand/logo/` (commit 9ee3d66, concept C "Bookmarked P", chosen
2026-11-19). That repo is the source of truth: change and regenerate the
files there (`npm run brand`), then copy them here. Don't edit them in place.

| File | Used for |
|---|---|
| `mark.svg` (also `/logo.svg`) | Brand mark; `BrandLogo` draws the same paths inline |
| `lockup-light.svg`, `lockup-dark.svg` | Mark + wordmark for emails/docs (light or dark backgrounds) |
| `/favicon-*.png`, `/apple-touch-icon-180.png`, `/icon-*.png` | Browser tab, home screen, PWA (wired in `src/app/layout.tsx`) |
